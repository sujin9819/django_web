META-Insight

Code for META-Insight, a framework that quantifies metagenome, metatranscriptome and metatranslatome (metaRibo-Seq) reads on one subject-specific reference: each subject's own metagenome-assembled genomes, folded into the pangenomes of the species detected in that subject. The scripts here build the species pangenome database, construct the reference, quantify the three layers, benchmark the reference against the CAMI II gold standard, reanalyse an external metaRibo-Seq cohort, and produce the analyses, figures and tables of the paper. The full analysis code is available on GitHub.

Running

Paths are read from two variables; config.sh sets them.
source config.sh # MI_ROOT = project tree, MI_DB = databases conda env create -f envs/.yml
Scripts are numbered in the order they were written; within a folder the list below is the order they run. Tools are called by name. Versions: bowtie2 2.4.5, msamtools 1.1.3, salmon 1.11.4, samtools 1.15, minimap2 2.28, featureCounts 2.0.6, trim_galore 0.6.10, fastp 0.23.4, sylph 0.9.0, skDER 1.3.4, skani 0.3.1, PanTA 1.0.1, DIAMOND 2.1.12, CD-HIT 4.8.1, pyrodigal 3.7.0, eggNOG-mapper 2.1.12 (eggNOG 5.0.2), CheckM2 1.0.2, GUNC 1.0.6, R 4.3.0, Python 3.10. Subjects are YUHS_1 to YUHS_5.
Detailed step-by-step instructions for some of the procedures can be found in the previous version
